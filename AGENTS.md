# Agent operating rules

- Read `docs/team/PROJECT_CONTEXT.md` and `docs/team/WORKFLOW.md` before work.
- Treat Markdown in `docs/` as the project source of truth.
- Every meaningful unit of work must have a stable task file in `docs/tracking/tasks/`.
- Update task status and handoff notes in the same PR as the implementation.
- Do not edit generated `dashboard/data/dashboard.json` by hand.
- Do not silently change accepted product or architecture decisions; propose an ADR.
- Use feature branches and pull requests. The project owner approves and merges changes.
- Keep changes scoped, tested, and documented.
