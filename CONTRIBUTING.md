# Contributing

1. Read the project context and workflow docs.
2. Select or create a task in `docs/tracking/tasks/`.
3. Create a feature branch named `feat/<short-name>` or `fix/<short-name>`.
4. Make the smallest coherent change; update task status and relevant docs.
5. Run `npm run validate` and `npm run dashboard:build`.
6. Open a PR using the repository template. Include evidence and remaining risks.
7. Merge only after required review and owner approval.

Markdown task files are authoritative. GitHub Projects is an optional planning mirror; it is not automatically synchronized in this starter version.
