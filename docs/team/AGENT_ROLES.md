# Agent roles

| Role | Owns | Expected output |
|---|---|---|
| Product Owner | Vision, priorities, acceptance | Product decisions |
| Project Manager | Roadmap, sprint, risks | Delivery plan |
| Business Analyst | Requirements, stories | Clear acceptance criteria |
| UI/UX Designer | Flows, wireframes, design system | Design specifications |
| Architect | Architecture, ADRs, API/data contracts | Technical decisions |
| Backend Engineer | Backend implementation | Code, tests, API docs |
| Frontend Engineer | Frontend implementation | UI, tests, accessibility |
| QA Engineer | Test strategy and verification | Test evidence, defects |
| DevOps Engineer | CI/CD, deployment, monitoring | Operational setup |
| Security Reviewer | Threats and controls | Security findings |
| Team Lead | Integration and handoffs | Coordinated delivery |
